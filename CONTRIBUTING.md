# Contributing

Issues and pull requests are welcome.

## Before you open a pull request

1. Build a debug APK with JDK 17: `gradle assembleDebug`
2. Keep new user-facing text in English in the source, and add the same phrase to the Hinglish map in `app/src/main/java/com/soumya/owed/Locale.kt` when you can.
3. Leave personal lending data on the device. Do not add a backend or analytics.
